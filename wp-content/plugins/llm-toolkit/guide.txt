LLM Toolkit plugin guide

Folders:
llm-toolkit/
	assets/
		css/
		js/
	config/
	includes/
		helpers/

Main functions folders:
llm-toolkit/ 	= plugin
assets/ 	    = where you can store what you need for your plugin's display page
css/		    = styling
js/		        = scripts
config/		    = configuration files
includes/	    = scripts to be included in the main plugin file
helpers/	    = helper methods for the admin display pages

Pages:
main page/settings page
status logs
bot logs

Flow:
